FPS SHOOTER - PROJECT SUMMARY
=============================

PROJECT OVERVIEW
----------------
A browser-based first-person shooter built with Three.js featuring precise hitbox detection, 
multiple enemy types, particle effects, and a complete game loop.

TECHNOLOGY STACK
----------------
- Three.js (r186) - 3D rendering engine
- Vite - Build tool and dev server
- Vanilla JavaScript (ES Modules) - No framework overhead
- WebGL - Hardware accelerated graphics
- Pointer Lock API - FPS mouse controls

CURRENT IMPLEMENTATION
----------------------

CORE SYSTEMS:

1. HitboxSystem (src/Hitbox.js)
   - Raycast-based precision hit detection
   - Per-mesh hitbox registration with damage multipliers
   - Head (3x damage) / Body (1x damage) zones
   - Debug visualization support
   - HitboxVisualizer for hit feedback rings

2. Player (src/Player.js)
   - Full FPS movement: WASD, sprint, jump, crouch-ready
   - Pointer lock mouse look with sensitivity control
   - Gun model with muzzle flash animation
   - Health/ammo/score management
   - Collision detection with environment
   - Audio feedback via Web Audio API (procedural tones)

3. TargetManager (src/Target.js)
   - 4 enemy types with unique stats:
     * Standard: 50 HP, 100 pts, 3 speed
     * Armored: 150 HP, 250 pts, 2 speed
     * Fast: 30 HP, 150 pts, 6 speed
     * Boss: 500 HP, 1000 pts, 1.5 speed
   - AI: Seek player, look-at targeting
   - Procedural spawning with difficulty scaling
   - Per-part hitboxes (head/body) with multipliers

4. ParticleSystem (src/Particles.js)
   - Hit spark particles with physics
   - Expanding hit rings (color-coded by damage)
   - Explosion effects on kill
   - Bullet trails
   - Muzzle flashes
   - Automatic lifecycle management

5. Environment (src/main.js)
   - Dynamic lighting: sun, fill, rim lights with shadows
   - Procedural floor with subtle displacement
   - Grid helper for orientation
   - 8 structural walls + 20 random props for cover
   - Fog for atmosphere and performance

GAME LOOP:
- Fixed timestep with delta clamping (max 0.1s)
- Player update → Targets update → Particles update → Render
- Auto-spawning targets (max 15, interval 1.5-3.5s)
- Score/health/ammo UI updates

UI ELEMENTS:
- Center crosshair
- Top-left stats (Score, Health, Ammo)
- Damage screen flash indicator
- Start menu / Game over screens

POTENTIAL ISSUES / PROBLEMS
---------------------------

PERFORMANCE:
- Particle creation/destruction every frame → GC pressure
- No object pooling for bullets, particles, targets
- Raycasting all hitboxes every shot (O(n) per shot)
- No spatial partitioning (octree/BVH) for hit detection
- Shadow map updates every frame for static objects

CODE QUALITY:
- No TypeScript - runtime errors only caught in browser
- No unit tests - regression risk
- No linting/formatting config
- Tight coupling between systems (Player knows TargetManager)
- Magic numbers scattered throughout
- No error boundaries / graceful degradation

GAMEPLAY:
- No difficulty curve - spawns purely time-based
- Enemies can stack/overlap
- No friendly fire / team system
- Jump physics feel floaty (low gravity)
- No crouch/prone
- No lean/peek mechanics
- Reload is instant (no animation/timing)

BROWSER COMPATIBILITY:
- Pointer Lock API requires user gesture (click) - handled
- Web Audio API requires user gesture - handled
- No fallback for WebGL2 unavailable
- No mobile support (touch controls)
- High memory usage on long sessions (leaks possible)

SECURITY:
- No client-side anti-cheat (irrelevant for SP, critical for MP)
- No input validation on networked data (future)

TASK 5: Configure Production Build
----------------------------------
1. Create vite.config.js:
```js
import { defineConfig } from 'vite'
export default defineConfig({
  build: {
    minify: 'terser',
    terserOptions: { compress: { drop_console: true } },
    rollupOptions: { output: { manualChunks: { three: ['three'] } } }
  },
  server: { port: 5173, open: true }
})
```

2. Add to package.json scripts:
```json
"build": "vite build",
"preview": "vite preview"
```

3. Test: npm run build && npm run preview
